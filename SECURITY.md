# Security Policy

## Supported Versions
We actively support and release security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security of **XIRUS Maps Extractor PRO** seriously.

1. **Do NOT** open a public issue for security vulnerabilities.
2. Please report vulnerabilities privately via [GitHub Security Advisories](https://github.com/MdNazmulHV/XIRUS-Maps-Extractor/security/advisories/new).
3. Provide detailed steps to reproduce the vulnerability.
4. You will receive an initial response within 48 hours.
