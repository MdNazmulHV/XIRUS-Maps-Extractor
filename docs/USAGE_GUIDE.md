# User & Operator Guide

Comprehensive instructions for operating **XIRUS Maps Extractor PRO**.

## 1. Getting Started
1. Navigate to [Google Maps](https://maps.google.com).
2. Search for any business, landmark, or public location.
3. Open the location details tab where photos or videos are listed.

## 2. Triggering Extraction
- Click the **XIRUS** icon from the Chrome toolbar.
- The Cyber-Glass HUD will initialize on the active tab.
- Select your desired extraction mode (**All Media**, **High-Res Photos Only**, or **Videos Only**).
- Click **Start Extraction**.

## 3. Storage & Output
- Extracted files are routed directly to your browser's default download folder under sub-directories named after the location.
