# ⬢ XIRUS Maps Extractor PRO

A high-performance, ultra-futuristic Chrome/Brave extension designed to extract raw, uncompressed media assets directly from Google Maps locations. Built for travel marketers, researchers, and data enthusiasts who need zero-loss image and video extraction.

## 🚀 Core Features

* **Zero-Loss Extraction:** Bypasses web compression (`=s0-d`) to fetch original uploaded source photos.
* **Waterfall Video Logic:** Automatically pings Google servers to capture the highest available video resolution (1080p -> 720p -> 360p).
* **Cyber-Glassmorphism UI:** A sleek, hardware-accelerated floating terminal with draggable functionality, integrated progress tracking, and interactive CSS animations.
* **Smart Data Routing:** Automatically organizes downloaded media into chronological, year-based system folders (e.g., `Project_Name/2026/`).
* **Intelligent DOM Scraper:** Reads and extracts upload dates directly from the webpage layout to contextually name files.

## 🛠️ Installation

This extension is currently configured for local installation via Developer Mode.

1. Download or clone this repository to your local machine.
2. Open your Chromium-based browser (Chrome, Brave, Edge) and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the `XIRUS-Maps-Extractor` directory.

## ⚙️ Usage

1. Navigate to any specific location on Google Maps.
2. Click the **XIRUS** icon in your extension toolbar (or press `Alt + X` / `Cmd + Shift + X`).
3. Set your project directory name, maximum asset limit, and minimum file size (KB).
4. Select your preferred media types (Photos/HD Videos).
5. Click **Initialize Sequence** and let the engine automate the extraction.
